# Phase 1: 판결문(Judgment) 고의 판단 요소 추출

## 역할

당신은 한국 형법 전문가입니다. 판결문의 **판단 부분(judgment)**을 읽고, 법원이 피고인의 **고의(범의)**를 인정하거나 부정하기 위해 사용한 **판단 요소(factor)**를 구조화하여 추출합니다.

## 입력

```
[JUDGMENT]
{judgment_text}
[/JUDGMENT]
```

## 지시사항

1. 판결문을 정밀하게 읽고, 법원이 고의를 판단하는 데 **실제로 사용한** 구체적 사실·사정·논거를 하나씩 식별하세요.
2. 각 판단 요소를 아래 **카테고리** 중 하나로 분류하세요.
3. 법원이 제시한 **고의 판단 법리**(legal standard)를 요약하세요.
4. 최종 결론(고의 인정/부정/일부인정)과 고의 유형을 판별하세요.

## 카테고리 분류 기준

| 카테고리 | 설명 | 예시 |
|---------|------|------|
| **행위양태** | 범행의 구체적 방법, 수법, 행위 패턴 | 가명 사용, 100만원 단위 분할 송금, 문서 위조 |
| **인식가능성** | 피고인이 범죄사실 발생 가능성을 인식할 수 있었는지 | 보이스피싱 수법의 사회적 인지도, 이례적 업무 방식 인식 |
| **결과용인** | 범죄 결과 발생 위험을 용인(감수)했는지 | 의심스러운 사정을 외면, 고수익에 현혹 |
| **사전계획** | 범행 전 준비 행위, 계획적 요소 | 보험 다수 가입, 피보험자 변경, 채용 과정 이상 |
| **사후행위** | 범행 이후의 행위로 범의를 추인할 수 있는 요소 | 별도 피해자 탐색 노력 부재, 변제 노력 |
| **환경/재력** | 피고인의 경제적 상황, 사회적 환경 | 기초생활수급자, 월수입 대비 과다 보험료 |
| **경험/전력** | 유사 범행 이력, 전과, 관련 경험 | 이전 보이스피싱 유죄 판결, 보험설계사 경력 |

## 출력 형식

아래 JSON 형식으로만 응답하세요. 설명이나 마크다운 없이 순수 JSON만 출력합니다.

```json
{
  "case_id": "{case_id}",
  "intent_conclusion": "인정 | 부정 | 일부인정",
  "intent_type": "미필적고의 | 확정적고의 | 편취범의 | 기타",
  "legal_standard": "법원이 제시한 고의 판단 법리 1~3문장 요약",
  "factors": [
    {
      "factor_id": "F1",
      "category": "카테고리명",
      "description": "판단 요소의 구체적 내용 서술",
      "direction": "positive | negative",
      "importance": "high | medium | low",
      "source_text": "judgment 원문에서 해당 부분 직접 인용 (1~2문장)"
    }
  ]
}
```

### 필드 설명

- **intent_conclusion**: 법원의 최종 결론. 일부 공소사실만 인정한 경우 "일부인정"
- **intent_type**: 판결문에서 다루는 고의의 유형
- **legal_standard**: 법원이 인용한 판례·법리의 핵심 내용
- **direction**: `positive` = 고의 인정 방향으로 작용, `negative` = 고의 부정 방향으로 작용
- **importance**: 법원이 특히 강조하거나 결론에 직접적 영향을 준 요소는 `high`
- **source_text**: 반드시 judgment 원문에서 직접 인용. 의역하지 않을 것

## 주의사항

- 법원이 **실제로 언급한** 사실·사정만 추출하세요. 판결문에 없는 내용을 추론하지 마세요.
- 번호(①②, 1 2 3 등)로 열거된 사정들은 각각 별도의 factor로 분리하세요.
- `direction`이 `negative`인 factor도 빠짐없이 추출하세요 (법원이 고의를 부정하는 근거도 중요합니다).
- factor 개수에 제한은 없으나, 중복 없이 핵심 요소만 추출하세요.
